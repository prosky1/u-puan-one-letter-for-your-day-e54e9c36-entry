Entry for the [make.fun bounty "One Letter for Your Day"](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36): exactly one letter, A–Z, standing for the word that describes the day.

## The letter

> O

Behind the letter sits the word **overcaffeinated** — vivid, funny, and true for a day spent building at full speed on too much coffee.

## How it works

`main.ts` writes the single letter `O` to `/output/entry.txt` (1 character, 1 byte), after checking it against the competition gate: exactly 1 character, one letter A–Z, not whitespace, and never the description's example letter Z. It reads the file back and confirms both the text and the byte size on disk.

Run it with Node 22 or later:

```sh
node main.ts
```
